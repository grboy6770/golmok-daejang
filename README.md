# 골목대장

서울 골목의 생활 데이터를 지도 한 장에 쌓는 프로젝트.
골목 사정을 다 꿰고 있는 **골목대장** + 골목 데이터를 기록한 **대장(臺帳)**.

## 레이어

| # | 레이어 | 상태 | 데이터 |
|---|--------|------|--------|
| 1 | 은행나무 편 — 가을 은행 냄새, 밟기 전에 미리 보기 | 공개 | [서울시 가로수 위치 정보](https://data.seoul.go.kr/dataList/OA-22904/S/1/datasetView.do) (2026-04-20) |
| 2 | 골목 소음 편 | 준비 중 | [S-DoT 도시데이터 센서 환경정보](https://data.seoul.go.kr/dataList/OA-15969/S/1/datasetView.do) |
| 3 | 쓰레기통 편 | 준비 중 | 자치구별 가로휴지통 현황 |

## 은행나무 편

서울 가로수 283,330그루 중 은행나무는 99,394그루(35%)다.
은행 열매 냄새는 **암나무**에서만 난다. 자치구 18곳의 데이터에는
"은행나무 암나무"(16,634그루)가 구분 표기돼 있어 냄새 발생원을 직접 표시한다.

- 빨간 점/열지도: 암나무 (열매·냄새 발생 확정)
- 노란 점: 암수 미표기 은행나무
- 성동·강북·은평·서대문·마포·강서·영등포·서초구는 암수 구분 없이 기록돼
  노란 점에도 암나무가 섞여 있을 수 있다

## 개발

```bash
# 데이터 재생성 (원본 xlsx → docs/data/*.json)
python3 scripts/build_trees.py

# 로컬 실행
cd docs && python3 -m http.server 8000
```

원본 데이터는 `data/raw/`에 보관한다. 서울 열린데이터광장에서 내려받은
`2026 서울시 가로수 위치정보.xlsx` (OA-22904, 연 1회 갱신).

## 데이터 출처·이용조건

- 서울 열린데이터광장, 서울특별시 (정원도시국 조경과)
- 공공누리 제4유형 (출처표시 + 상업적 이용금지 + 변경금지) — 본 프로젝트는 비상업 개인 프로젝트이며 출처를 표시한다
